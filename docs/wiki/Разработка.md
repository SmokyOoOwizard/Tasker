# Разработка

Нужны .NET SDK 10 и Node.js с npm; остальное тянется через NuGet и npm.

## Структура

| Папка | Что там |
|---|---|
| `frontend/` | React + TypeScript (Vite), единственный фронтенд |
| `src/Tasker.Core` | домен и сервисы |
| `src/Tasker.Configs` | настройки из переменных окружения и аргументов |
| `src/Tasker.Storage.Files`, `src/Tasker.Storage.Db` | хранение файлами (`.tasker`) и в БД (EF Core: SQLite, Postgres) |
| `src/Tasker.Mcp` | инструменты MCP поверх сервисов Core |
| `src/Tasker.Web` | API и встроенный фронтенд (`frontend/dist` как ресурс) |
| `src/Tasker.Server`, `src/Tasker.Desktop` | хосты: ASP.NET Core и Avalonia (Web in-process на 127.0.0.1) |
| `src/Tasker.Cli` | консоль `tasker` (System.CommandLine) |
| `src/Tasker.Global`, `src/Tasker.Daemon`, `src/Tasker.Daemon.Host` | глобальные настройки; управление демоном и автозапуск; сам демон `tasker-mcpd` |
| `tests/Tasker.Tests` | тесты xUnit |
| `tools/Tasker.Stress` | стенд параллельной работы |
| `scripts/` | установка, релиз, тесты в Docker |

## Сборка и запуск

Фронтенд встраивается при сборке .NET, поэтому сначала он:

```bash
cd frontend && npm install && npm run build
dotnet build
```

| Что | Команда |
|---|---|
| Сервер (:5156, SQLite в памяти) | `dotnet run --project src/Tasker.Server` |
| Сервер с файлом SQLite | `dotnet run --project src/Tasker.Server -- --sqlite=tasker.db` |
| Десктоп | `dotnet run --project src/Tasker.Desktop` (`-- --files=<папка>` откроет вкладку сразу) |
| Фронтенд с hot reload | сервер, затем `cd frontend && npm run dev` (Vite на :5173, `/api` идёт на :5156) |
| Десктоп с Vite | `TASKER_FRONTEND_DEV_URL=http://localhost:5173 dotnet run --project src/Tasker.Desktop` (Vite проксирует `/w/<папка>/api` и `/mcp` на порт 5719) |

Боевые настройки сервера (Postgres, ключ подписи): [Настройка и сервер](Настройка-и-сервер). Линтер фронтенда: `npm run lint`. Сборка без встраивания фронтенда (консоль, тесты): `-p:EmbedFrontend=false`.

## Тесты

```bash
dotnet test                                                             # все
dotnet test tests/Tasker.Tests --filter "FullyQualifiedName~CliTests"   # по фильтру
scripts/test-linux.sh [--filter "..."]    # на Linux в Docker (нужен docker)
scripts/test-linux.sh --stress "upgrade"  # стенд вместо тестов
```

- Тесты сквозные: настоящее хранилище (файлы и SQLite), процессы `tasker`, демон на свободном порту с отдельным `TASKER_HOME`; launchctl и systemctl подменены.
- Идут параллельно: окружение переопределяется через `AppEnvironment.Override`; менять переменные окружения и текущую папку всего процесса в тестах нельзя.
- Нужны `git` (хуки) и `python3` (проверка чужой блокировки).
- Тест под конкретную ОС помечается `[PlatformFact(TestPlatform.Windows)]`: на других системах он считается пропущенным.
- `scripts/test-linux.sh` копирует исходники в контейнер и запускает тесты не от root; у скрипта есть также `--platform`, `--log`, `--shell`.

Стенд параллельной работы (временная папка, свой демон; данные и демон на 5719 не трогает; код возврата 1 при нарушении инвариантов):

```bash
dotnet run -c Release --project tools/Tasker.Stress -- --clients 10 --client mix --scenarios create,locks
```

Остальные ключи: `--ops`, `--storage files|sqlite`, `--scale`, `--long`, `--keep`, `--dir`, `--json`, `--seed`.

## Устройство

- DI: Autofac. `TaskerWebApp.CreateBuilder<THostModule>()` подключает `CoreModule` и `WebModule`, хост добавляет `ServerModule` или `DesktopModule`.
- Логи: Serilog, настраивается в `Program` хоста. Сервер пишет в консоль; десктоп ещё и в `logs/tasker-*.log` каталога данных (файл на час, хранятся 23 часа).

| Добавить | Шаги |
|---|---|
| Команду консоли | класс в `src/Tasker.Cli/Commands`, регистрация `Add(...)` в `CliApp.BuildRoot` |
| Инструмент MCP | статический метод с `[McpServerTool(Name = "...")]` и `[Description]` в классе `[McpServerToolType]` в `src/Tasker.Mcp/Tools`; сервисы приходят параметрами |
| Страницу интерфейса | компонент в `frontend/src/pages`, маршрут в `frontend/src/App.tsx` |

Релиз: `scripts/release.sh` (архивы и SHA256 по платформам, версия из файла `VERSION`); установка — [Установка](Установка).
