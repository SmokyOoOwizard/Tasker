# Tasker

Tasker — трекер задач, который живёт рядом с кодом. Проекты, задачи, статусы, доски, серии и связи хранятся обычными файлами в папке `.tasker` внутри вашего репозитория (их версионирует git) либо в базе данных. Работать с ними можно из консоли, из десктопного и веб-интерфейса и из ИИ-агентов через MCP.

## Что умеет

- **Задачи и порядок работы.** Проекты, статусы и наборы статусов, типы задач, доски с колонками (колонка = статусы и необязательные условия по полям), серии со сквозными номерами (`TSK-12`).
- **Связи и иерархия.** Блокировки, дубликаты, клоны, «входит в»: эпик показывается в `task list` вместе с вложенными задачами, у задачи может быть несколько родителей. Циклы запрещены.
- **Свои поля.** Строки, числа, даты, флаги и перечисления (в том числе несколько значений), обязательные поля, поля у типа задачи и у отдельной задачи.
- **Поиск.** Фильтры по статусам, типам, сериям и полям (`=`, `!=`, `>`, `<`, «есть значение»), сортировка, постраничный вывод.
- **Для агентов.** MCP-сервер с инструментами для задач, досок и связей; один общий адрес для всех проектов; демон с автозапуском, который обновляется без простоя.
- **Совместная работа.** Блокировка записи на время правки и проверка версии: десять параллельных клиентов не теряют правки друг друга. Конфликты слияния git разбираются командами `tasker sync` и `tasker cleanup`.
- **Удобная консоль.** `tasker` с автодополнением по Tab (zsh, bash, PowerShell), встроенный справочник `tasker manual`, выровненный вывод, обрезка строк по ширине окна.
- **Платформы.** macOS, Linux и Windows. Что и насколько проверено — на страницах [Linux](Linux) и [Windows](Windows).
