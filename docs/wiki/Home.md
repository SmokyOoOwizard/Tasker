# Tasker

Трекер задач, который живёт рядом с кодом. Проекты, задачи, статусы, доски, серии и связи хранятся файлами в папке `.tasker` вашего репозитория (их версионирует git) или в базе данных. Работать можно из консоли, из десктопного и веб-интерфейса, а ИИ-агенты подключаются через MCP.

## Что умеет

- **Задачи и доски:** статусы и их наборы, типы задач, доски с колонками, серии со сквозными номерами (`TSK-12`).
- **Связи и поля:** блокировки, дубликаты, эпики с вложенными задачами; свои поля, перечисления, обязательные значения.
- **Поиск:** фильтры по статусам, типам, сериям и полям, сортировка, постраничный вывод.
- **Агенты:** MCP-сервер и фоновый демон с автозапуском, обновляется без простоя.
- **Совместная работа:** блокировка на время правки, проверка версии, разбор конфликтов слияния git.
- **Платформы:** macOS, Linux, Windows (на Windows пока экспериментально).
