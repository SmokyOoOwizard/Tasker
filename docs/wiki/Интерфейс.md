# Интерфейс

Один и тот же веб-интерфейс (React) работает в браузере с сервером. Он покрывает проекты, задачи, доски, статусы, типы задач, участников и агентов; остальное (поля, связи, серии, синхронизация git) — в [консоли](Консоль) и через [MCP](MCP-и-агенты).

## Поставки

| Поставка | Что это |
|---|---|
| Server | интерфейс в браузере, вход по логину, несколько пользователей |
| Консоль | `tasker` и демон MCP, без графики ([Установка](Установка)) |

Режимы и параметры сервера: [Настройка и сервер](Настройка-и-сервер).

## Навигация

Слева сайдбар: выбор проекта (открывается при наведении, там же «Новый проект»), разделы проекта, пользователь. Последний проект запоминается и открывается по `/`.

| Адрес | Что там |
|---|---|
| `/projects/{id}/tasks` | список задач (по 50), создание (название и тип), смена статуса |
| `/projects/{id}/boards` | доски: название, колонки, наборы статусов |
| `/projects/{id}/settings/statuses` | статусы и наборы статусов |
| `/projects/{id}/settings/task-types` | типы задач и их наборы статусов |
| `/projects/{id}/settings/members` | участники проекта, люди и агенты (только Server) |
| `/projects/{id}/settings/project` | переименование и удаление проекта (удаление после ввода названия) |
| `/profile`, `/profile/agents` | настройки пользователя и агенты |

## Комментарии

В карточке задачи, полной и в боковой панели, есть раздел «Комментарии»: дерево ответов от людей и агентов. У агента квадратный значок и пометка «агент». Ответить можно на любой комментарий, изменить и удалить только свой: эти кнопки появляются при наведении. Удалённый комментарий с ответами остаётся пометкой. Отступ растёт до 6 уровней в полной карточке и до 4 в панели, глубже появляется кнопка «Продолжить ветку», которая показывает эту часть отдельно. Ветку можно свернуть. Дерево обновляется само, когда комментарий появляется из консоли, MCP или git.

## Сервер

- Без входа любой адрес ведёт на экран входа; пока пользователей нет, регистрируется первый (админ).
- «Выйти» появляется при наведении на пользователя в сайдбаре; сессия отзывается на сервере.
- В настройках: имя, почта, смена пароля (остальные сессии при этом завершаются).
- Участники: добавить можно любого человека и своего агента (админ — любого), убрать — любого, кроме последнего человека.

## Агенты

Вкладка «Агенты» (`/profile/agents`): создание, переименование, удаление.

- Server: токены агента с названием и сроком (без срока, 30, 90 дней, год), отзыв, время последнего использования. Значение токена показывается один раз вместе с командой `claude mcp add`. Доступ к проекту выдаётся через участников.

Подробнее: [MCP и агенты](MCP-и-агенты), [Демон MCP](Демон-MCP).

Ограничения: экран обновляется после своих изменений; при конфликте версий данные перечитываются и правку нужно повторить.
