# Интерфейс

Один и тот же веб-интерфейс (React) работает в браузере с сервером и в окне десктопа. Он покрывает проекты, задачи, доски, статусы, типы задач, участников и агентов; остальное (поля, связи, серии, синхронизация git) — в [консоли](Консоль) и через [MCP](MCP-и-агенты).

## Поставки

| Поставка | Что это |
|---|---|
| Server | интерфейс в браузере, вход по логину, несколько пользователей |
| Desktop | окно с тем же интерфейсом, без входа; рабочая область — папка с `.tasker` или файл SQLite |
| Консоль | `tasker` и демон MCP, без графики ([Установка](Установка)) |

Режимы и параметры сервера: [Настройка и сервер](Настройка-и-сервер).

## Навигация

Слева сайдбар: выбор проекта (открывается при наведении, там же «Новый проект»), разделы проекта, пользователь. Последний проект запоминается (на десктопе отдельно для каждой папки) и открывается по `/`.

| Адрес | Что там |
|---|---|
| `/projects/{id}/tasks` | список задач (по 50), создание (название и тип), смена статуса |
| `/projects/{id}/boards` | доски: название, колонки, наборы статусов |
| `/projects/{id}/settings/statuses` | статусы и наборы статусов |
| `/projects/{id}/settings/task-types` | типы задач и их наборы статусов |
| `/projects/{id}/settings/members` | участники проекта, люди и агенты (только Server) |
| `/projects/{id}/settings/project` | переименование и удаление проекта (удаление после ввода названия) |
| `/profile`, `/profile/agents` | настройки пользователя и агенты |

## Сервер

- Без входа любой адрес ведёт на экран входа; пока пользователей нет, регистрируется первый (админ).
- «Выйти» появляется при наведении на пользователя в сайдбаре; сессия отзывается на сервере.
- В настройках: имя, почта, смена пароля (остальные сессии при этом завершаются).
- Участники: добавить можно любого человека и своего агента (админ — любого), убрать — любого, кроме последнего человека.

## Агенты

Вкладка «Агенты» (`/profile/agents`): создание, переименование, удаление.

- Server: токены агента с названием и сроком (без срока, 30, 90 дней, год), отзыв, время последнего использования. Значение токена показывается один раз вместе с командой `claude mcp add`. Доступ к проекту выдаётся через участников.
- Desktop: токенов нет; после создания агента (и по кнопке «Подключить») показывается команда `claude mcp add` с адресом MCP этой папки и заголовком `X-Tasker-Agent`.

Подробнее: [MCP и агенты](MCP-и-агенты), [Демон MCP](Демон-MCP).

## Десктоп

- Рабочие области открываются вкладками. Сразу с папкой: аргумент `--files=<папка>` (файл SQLite: `--sqlite=<файл>`); повторный запуск передаёт запрос уже работающему экземпляру.
- Закрытие окна прячет его, приложение остаётся в трее. Открыть: клик по иконке трея, «Открыть» в её меню, иконка Dock. Выход: Cmd+Q, «Выйти из Tasker», «Выход» в меню трея.

| Действие | macOS | Windows и Linux |
|---|---|---|
| Новая вкладка / окно | Cmd+T / Cmd+N | Ctrl+T / Ctrl+N |
| Открыть папку | Cmd+O | Ctrl+O |
| Закрыть вкладку | Cmd+W | Ctrl+W |
| Закрыть окно | Cmd+Shift+W | только из меню |
| Следующая / предыдущая вкладка | Cmd+Shift+] / Cmd+Shift+[ или Ctrl+Tab / Ctrl+Shift+Tab | Ctrl+Tab / Ctrl+Shift+Tab |
| Вкладка по номеру | Cmd+1…8; Cmd+9 — последняя | Ctrl+1…8; Ctrl+9 — последняя |

Ограничения: экран обновляется после своих изменений, на десктопе ещё и по событиям рабочей области; при конфликте версий данные перечитываются и правку нужно повторить.
