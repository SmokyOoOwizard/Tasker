# Интерфейс

- **Сайдбар** слева: сверху выбор проекта, под ним разделы проекта, внизу — пользователь. Клик по пользователю открывает его настройки (`/profile`).
- **Выбор проекта** — список всплывает справа при наведении, там же «Новый проект». При смене проекта открывается тот же раздел. Последний открытый проект запоминается (на десктопе — отдельно для каждой папки) и открывается по `/`; если проектов нет — создание первого.
- **Разделы проекта** — адреса `/projects/{id}/…`, чтобы вкладка десктопа переоткрывалась там же:
  - `tasks` — все задачи проекта: список страницами по 50, создание (название и тип), смена статуса из набора типа;
  - `boards` — все доски проекта: название, колонки, наборы статусов;
  - `settings/statuses` — статусы (название, цвет, описание) и наборы статусов (состав и порядок); `settings/task-types` — типы задач (название, описание, набор статусов).
  - `settings/members` (только сервер) — участники: люди и агенты. Добавить можно любого человека и своего агента (админ — любого), убрать — любого, кроме последнего человека. Вышедший из проекта не-админ теряет к нему доступ и попадает на `/`;
  - `settings/project` — переименование и удаление проекта; удаление — после ввода названия проекта.
- **Обновление данных:** после своих изменений экран перечитывает данные; на десктопе — ещё и по событиям рабочей области (один поток SSE на вкладку). Конфликт версий (409 `modified`) перечитывает данные и просит повторить изменение.
- **Сервер:** без входа по любому адресу показывается экран входа, после входа открывается тот же адрес. Пока пользователей нет — вместо входа регистрация первого (админа). При наведении на пользователя в сайдбаре появляется «Выйти»: сессия отзывается на сервере, все вкладки браузера возвращаются к экрану входа. В настройках — имя, почта и смена пароля; после смены пароля остальные сессии завершаются, а эта сразу входит заново с новым паролем.
- **Десктоп:** входа нет, поэтому нет и «Выйти»; в настройках — пояснение про локальный режим.
- **Агенты** — вкладка «Агенты» в настройках пользователя (`/profile/agents`): создание, переименование и удаление агентов. На сервере — свои агенты (админу — все, с владельцем) и их токены: выпуск с названием места использования и сроком (без срока, 30, 90 дней, год), отзыв, время последнего использования. Значение токена показывается один раз, сразу с командой `claude mcp add` для этого сервера. Доступ агента к проекту — через участников проекта. На десктопе токенов нет: после создания агента (и по кнопке «Подключить») показывается команда `claude mcp add` с адресом MCP этой папки и заголовком `X-Tasker-Agent: <id агента>`.
- **Токены** (`frontend/src/auth.ts`) — в `localStorage`, общие для всех вкладок. Access-токен обновляется за 30 секунд до истечения и при ответе 401. Обмен refresh-токена идёт под блокировкой Web Locks, общей для вкладок: вкладка, дождавшаяся блокировки, берёт уже обменянный соседкой токен, поэтому параллельного обмена одного токена (он отзывает сессию) не бывает.

## Поведение десктопа

- Закрытие окна прячет его, приложение продолжает работать.
- Окно снова открывается кликом по иконке в трее, через пункт «Открыть» в её меню или кликом по иконке в Dock.
- Выход: Cmd+Q, «Выйти из Tasker» в меню приложения, «Выход» в меню трея или «Завершить» в Dock.
