# Строка запроса

Строка над списком задач и над доской отбирает и сортирует задачи одним выражением. Запрос применяется сам, как только становится правильным, и хранится в состоянии окна: у списка один, у каждой доски свой. Неверный запрос подчёркивается красным, под строкой появляется сообщение, а на экране остаётся последний правильный результат.

```
(.Status == "Todo" || .Status == "Doing") && .Field.Estimate > 3 | sort .Status, -.Updated
```

## Условия

Условие начинается с точки. Условия соединяются операторами `&&` (И) и `||` (ИЛИ), `!` отрицает условие или скобки. `&&` выполняется раньше `||`, порядок меняют круглые скобки.

| Свойство | Что это | Операторы | Функции |
| --- | --- | --- | --- |
| `.Status` | статус | `==` `!=` | |
| `.Type` | тип задачи | `==` `!=` | |
| `.Title` | заголовок, регистр не важен | `==` `!=` | `Contains` |
| `.Series` | серии задачи, по префиксу | `==` `!=` | `Contains` `ContainsAny` `ContainsAll` `IsSet` `IsUnset` |
| `.Created` | когда задача создана, время UTC | `==` `!=` `>` `>=` `<` `<=` | |
| `.Updated` | когда задача обновлена, время UTC | `==` `!=` `>` `>=` `<` `<=` | |
| `.Field.Имя` | поле каталога или собственное поле | зависят от типа | см. ниже |
| `.Link.Имя` | связь этого типа | | `IsSet` `IsUnset` |
| `.Parent` | есть родитель по иерархической связи | | `IsSet` `IsUnset` |

Регистр в именах свойств, функций, статусов, типов и полей не важен. Имя с пробелами пишется в кавычках: `.Field."Тестовое поле" == 2`.

`.Link.Blocks` и `.Link.blocks` ищут исходящую связь по названию типа или её стороны, `.Link."is blocked by"` — входящую.

## Значения

- Текст в двойных кавычках: `"Todo"`. Кавычка внутри текста пишется как `\"`.
- Числа: `3`, `-1.5`. Логические значения: `true`, `false`. Дата — текст `"2026-11-05"` (см. «Даты»).
- Значения перечисления пишутся названиями.
- Массив: `["Todo", "Done"]`.

## Сравнения

- `==` и `!=` есть у всех значений. `!=` всегда отрицает `==`.
- `>`, `>=`, `<`, `<=` есть только у полей типа int, float и date, а также у `.Created` и `.Updated`. У поля с несколькими значениями достаточно одного подходящего значения.
- Поле с одним значением, `.Status`, `.Type`, `.Title`: массив справа значит «одно из», `!=` с массивом — «ни одно из».
- Поле с несколькими значениями и `.Series`: `==` значит, что есть только эти значения, порядок не важен. `.Field.Метки == ["bug", "ui"]` подходит задаче с `ui, bug`, но не с `bug, ui, docs`. Собственное поле считается полем с несколькими значениями, если оно такое хотя бы у одной задачи.

## Даты

Даты пишутся текстом в кавычках и читаются в UTC. Для `.Created` и `.Updated` годятся такие записи:

| Запись | Что значит |
| --- | --- |
| `"2026-11-05"` | сутки целиком |
| `"2026-11-05T14:30"` | эта минута |
| `"2026-11-05T14:30:15"` | эта секунда |
| `"today"` | сегодняшние сутки |
| `"today-7d"`, `"today+1w"` | сутки со сдвигом на дни (`d`) или недели (`w`) |
| `"now"` | текущая секунда |
| `"now-3h"`, `"-7d"` | момент со сдвигом от «сейчас»: минуты `m`, часы `h`, дни `d`, недели `w`; запись без `now` и `today` считается от «сейчас» |

Запись задаёт отрезок времени, а сравнение берёт его целиком:

- `.Created == "2026-11-05"` — создана в эти сутки, `!=` — в другое время.
- `.Created > "2026-11-05"` — после конца суток, `>=` — с начала суток.
- `.Created < "2026-11-05"` — до начала суток, `<=` — до конца суток.

Пример: `.Created >= "2026-11-01" && .Updated < "today-7d"`. Относительные значения считаются в момент разбора запроса. Массив справа и число без кавычек не принимаются. Неверная запись даёт ошибку `query.badDate` с подчёркиванием значения.

Поля типа date понимают те же сутки со сдвигом: `.Field.Срок >= "today"`, `.Field.Срок < "today-7d"`. Время в них не бывает, поэтому записи с временем и сдвиг в часах и минутах дают ошибку; `"-7d"` без `today` тоже превращается в дату.

## Функции

| Функция | Смысл |
| --- | --- |
| `.Field.Метки.Contains("bug")` | значение есть среди других |
| `.Field.Метки.ContainsAny(["bug", "ui"])` | есть хотя бы одно из значений |
| `.Field.Метки.ContainsAll(["bug", "ui"])` | есть все значения |
| `.Title.Contains("логин")` | заголовок содержит текст |
| `.Field.Estimate.IsSet()` | у поля есть значение |
| `.Field.Estimate.IsUnset()` | значения нет, в том числе поле не подключено |
| `.Field.Estimate.IsAttached()` | поле подключено: входит в тип задачи или добавлено ей |
| `.Field.Estimate.IsDetached()` | поле не подключено |

`Contains`, `ContainsAny` и `ContainsAll` работают только у полей с несколькими значениями, `.Series` и (`Contains`) `.Title`.

## Сортировка

Сортировка пишется в конце после `| sort`, ключи идут через запятую, минус означает убывание: `| sort .Status, -.Updated, .Field.Estimate`. Ключи: `.Status`, `.Type`, `.Title`, `.Created`, `.Updated`, `.Series`, `.Field.Имя`. Условий при этом может не быть: `| sort .Title`.

`.Created` и `.Updated` доступны и в условиях, и в сортировке. Сортировка из строки главнее сортировки списка: пока она задана, кнопки сортировки скрыты.

## Текст без точки

Текст без точки считается ошибкой, а в подсказках появляется `.Title.Contains("текст")`. Нечёткий поиск по номеру, заголовку и описанию находится в палитре команд.

## Подсказки

Подсказки появляются при вводе и зависят от места в строке: свойства, поля проекта, типы связей, статусы, типы, серии, значения перечислений, функции и операторы. После `.Created` и `.Updated` предлагаются все сравнения, а в значении — `"today"`, `"today-7d"`, `"now"`, `"-7d"` и другие, с подсказкой о формате. У полей типа date предлагаются `"today"` и сдвиги по дням.

| Клавиша | Действие |
| --- | --- |
| ↑ ↓ | выбрать подсказку, открыть закрытый список |
| Tab | подставить выбранную или первую подсказку |
| Enter | подставить выбранную подсказку, без выбора — применить запрос и закрыть список |
| Esc | закрыть список, в закрытом — выйти из строки |

## Для разработчиков

Разбор и подсказки находятся в `Tasker.Core/Tasks/Query`, клиенты их не повторяют. Поле GraphQL `project.taskQueryAnalysis(text, cursor)` возвращает `valid`, `hasSort`, ошибки (`code`, `params`, `message`, `start`, `end`) и подсказки (`label`, `insert`, `start`, `end`, `caret`, `kind`, `detail`). Позиции считаются в единицах UTF-16. Поля `tasks`, `taskTree` и `columnTasks` принимают аргумент `query`, неверный запрос отклоняется с кодом ошибки `query.*`. Запрос превращается в дерево `TaskPredicate` в `TaskFilter.Predicate`: оба хранилища выполняют его запросом и соединяют с остальными условиями фильтра через И.
