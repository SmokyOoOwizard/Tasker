# Установка

Tasker ставится из релиза: архив содержит самодостаточную сборку (`tasker` и демон `tasker-mcpd`), .NET и права администратора не нужны.

| Система | Архив | Установщик | Автозапуск демона |
|---|---|---|---|
| macOS (arm64, x64) | `tasker-<версия>-osx-arm64.tar.gz`, `-osx-x64.tar.gz` | `install.sh` | launchd (агент пользователя) |
| Linux (glibc, x64, arm64) | `-linux-x64.tar.gz`, `-linux-arm64.tar.gz` | `install.sh` | systemd `--user` |
| Windows 10 1809+ (x64, arm64) | `-win-x64.zip`, `-win-arm64.zip` | `install.ps1` | Планировщик заданий |

Требования: Linux — библиотека ICU (`libicu`, установщик предупредит, если её нет); Alpine (musl) не поддерживается. Windows: поддержка экспериментальная, на самой Windows ещё не проверялась ([Платформы](Платформы)).

## Установка

```bash
tar -xzf tasker-0.1.0-osx-arm64.tar.gz && tasker-0.1.0-osx-arm64/install.sh   # из распакованного релиза
install.sh --from tasker-0.1.0-linux-x64.tar.gz                                # из архива или каталога со сборкой
install.sh --url https://<адрес>/tasker-0.1.0-linux-x64.tar.gz                 # скачать; проверяется .sha256 рядом
```

```powershell
Expand-Archive tasker-0.1.0-win-x64.zip .; .\tasker-0.1.0-win-x64\install.ps1  # или: .\install.ps1 -From архив.zip
```

Повторный запуск — обновление, `--uninstall` / `-Uninstall` — удаление.

### install.sh (macOS, Linux)

| Параметр | Что делает |
|---|---|
| `--from ПУТЬ` | архив `.tar.gz` или каталог с готовой сборкой |
| `--url АДРЕС` | скачать архив; `--no-verify` — без файла суммы |
| `--from-source` | собрать из исходников (нужен .NET SDK 10); `--framework-dependent` — маленькая сборка, нужен .NET 10 runtime; `--no-daemon` — только консоль |
| `--prefix DIR` | другой каталог (по умолчанию `~/.local`) |
| `--add-to-path` | дописать `<prefix>/bin` в PATH профиля оболочки |
| `--no-autostart` | не включать автозапуск демона |
| `--no-completion` | не подключать автодополнение к оболочке |
| `--restart` | перезапустить работающий демон (иначе он переключается на новую сборку без простоя) |
| `--uninstall` | удалить |

### install.ps1 (Windows)

| Параметр | Что делает |
|---|---|
| `-From ПУТЬ`, `-Url АДРЕС` (`-NoVerify`) | архив `.zip` или папка со сборкой; скачивание с проверкой `.sha256` |
| `-Prefix ПАПКА` | другая папка (по умолчанию `%LOCALAPPDATA%\Programs\Tasker`) |
| `-NoPath`, `-NoCompletion`, `-NoAutostart` | не менять PATH, не подключать автодополнение, не включать автозапуск |
| `-DryRun` (`-WhatIf`) | только показать действия |
| `-Uninstall` | удалить |

## Что ставится куда

| Что | macOS, Linux | Windows |
|---|---|---|
| Программы | `<prefix>/share/tasker/app/` | `<Prefix>\app\` |
| Команда | `<prefix>/bin/tasker` (ссылка) | `<Prefix>\app` в пользовательском PATH |
| Скрипты автодополнения | `<prefix>/share/tasker/completions/` | `tasker completion pwsh --install` |
| Данные, настройки, логи | `~/Library/Application Support/Tasker` (macOS), `~/.local/share/Tasker` (Linux) | `%LOCALAPPDATA%\Tasker` |

Установщик копирует сборку во временную папку, проверяет её дымовым тестом и только потом заменяет установку целиком: сломанная сборка рабочую не затрагивает. Путь к программе стабилен, поэтому автозапуск и git-хуки переживают обновление.

- **Автозапуск.** Если он не включён, установщик выполняет `tasker mcp autostart enable` (демон сразу стартует); не вышло (например, нет systemd) — предупреждение, установка остаётся. Подробнее: [Демон MCP](Демон-MCP).
- **Автодополнение.** В `~/.zshrc` или файл bash добавляется один помеченный блок (копия `.tasker-backup`); подробнее: [Консоль](Консоль#автодополнение-по-tab).
- **PATH.** Если `<prefix>/bin` не в PATH, скрипт печатает строку для профиля; `--add-to-path` дописывает её сам.
- **Windows.** Перед заменой файлов демон останавливается и затем запускается снова.

## Обновление и удаление

Обновление — повторный запуск установщика новой версии. Удаление выключает автозапуск, останавливает демон и убирает программу, ссылку, скрипты автодополнения и свой блок в файле оболочки. Данные и рабочие папки с `.tasker` не трогаются; git-хуки остаются и без `tasker` ничего не делают (`tasker hooks uninstall` уберёт их заранее).

## Сборка релиза

```bash
scripts/release.sh                          # все платформы -> artifacts/release/<версия>/
scripts/release.sh --rid osx-arm64,win-x64  # выбранные (win-x64 win-arm64 linux-x64 linux-arm64 osx-arm64 osx-x64)
scripts/release.sh --no-r2r --out DIR       # без ReadyToRun: быстрее сборка, медленнее старт
```

Для каждой платформы скрипт публикует `tasker` и `tasker-mcpd` в одну папку `app/`, добавляет установщик и `release.txt`, пакует в `tasker-<версия>-<rid>.tar.gz` (Windows — `.zip`) и пишет `.sha256` и общий `SHA256SUMS` (`shasum -a 256 -c SHA256SUMS`). Собирать можно с любой системы (при первой сборке нужна сеть). Прочие параметры: `--version`, `--no-archive`, `--keep-work`.

Версия одна на все программы — файл `VERSION` в корне; `tasker --version` печатает её. Выпуск: правка `VERSION`, коммит, тег `v<версия>`, `scripts/release.sh` (тег должен совпадать с файлом).

Сборка и запуск из исходников: [Разработка](Разработка).
