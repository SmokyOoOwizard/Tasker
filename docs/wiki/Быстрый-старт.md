# Быстрый старт

Пять минут от пустой папки до первой доски. Нужна установленная утилита `tasker` ([Установка](Установка)). Все команды работают в текущей папке: данные появятся в `./.tasker`, сервер и база не нужны.

## 1. Проект, статусы и типы задач

```bash
tasker project create Demo
tasker status create "Бэклог"
tasker status create "В работе"
tasker status create "Готово"
tasker status-set create Поток --status "Бэклог" "В работе" "Готово"
tasker task-type create Задача --status-set Поток
tasker task-type create Баг --status-set Поток
tasker series create Задачи --prefix TSK
```

Набор статусов («Поток») — это допустимые состояния и их порядок; тип задачи привязан к набору. Серия даёт задачам номера `TSK-1`, `TSK-2` и так далее. Если в папке один проект, параметр `-p` не нужен.

## 2. Задачи

```bash
tasker task create "Первая задача" --type Задача --series TSK
tasker task create "Починить вход" --type Баг --series TSK -d "Падает при пустом пароле"
tasker task update TSK-2 --status "В работе"
tasker task list
```

```
Found 2
TSK-1  Бэклог    Задача  Первая задача
TSK-2  В работе  Баг     Починить вход
```

Первой строкой всегда идёт число найденного. Фильтры, сортировка и вывод для скриптов: `tasker task list --help`, [Консоль](Консоль).

## 3. Эпик и вложенные задачи

```bash
tasker task link TSK-1 includes TSK-2
tasker task list
```

```
Found 2
TSK-1      Бэклог    Задача  Первая задача
    TSK-2  В работе  Баг     Починить вход
```

`includes` делает `TSK-1` эпиком: вложенные задачи показываются под ним с отступом, `--flat` возвращает плоский список. Подробнее: [Связи и поля](Связи-и-поля).

## 4. Доска

```bash
tasker board create Основная --status-set Поток \
  --column "Бэклог=Бэклог" --column "Работа=В работе" --column "Готово=Готово"
tasker board show Основная
```

```
Бэклог (1)
  TSK-1  Бэклог    Задача  Первая задача

Работа (1)
  TSK-2  В работе  Баг     Починить вход

Готово (0)
  (no tasks)
```

Задача попадает в колонку по статусу, поэтому переносить её руками не нужно: достаточно сменить статус.

## 5. Дальше

- **Файлы в git.** Папка `.tasker` — обычные YAML-файлы: коммитьте их вместе с кодом. После `git pull` выполните `tasker sync` (или поставьте хуки: `tasker hooks install`).
- **Справочник.** `tasker manual` — короткие рецепты «как сделать»; `tasker --help` — все команды.
- **Агенты.** Подключите MCP-сервер, и ИИ-агент сможет читать и менять задачи:

  ```bash
  tasker mcp autostart enable
  claude mcp add --transport http tasker http://127.0.0.1:5719/mcp
  ```

  Подробнее: [MCP и агенты](MCP-и-агенты), [Демон MCP](Демон-MCP).
- **Поля, серии, фильтры.** [Связи и поля](Связи-и-поля), [Концепции](Концепции).
