# Миграция формата файлов

Привести файлы `.tasker` к текущей версии формата, когда программа обновилась, а папка осталась прежней.

## Что нужно

Папка с `.tasker` под git (или хотя бы копия: миграция переписывает файлы). SQLite-файлу миграция не нужна.

## Шаги

Сначала посмотреть, что изменится, ничего не записывая:

```bash
tasker migrate --dry-run
```

Затем выполнить, а в скриптах и CI проверять без записи:

```bash
tasker migrate
tasker migrate --check
```

## Пример

```text
$ tasker migrate --check
Nothing to migrate: all 19 file(s) are in the current format (5)
```

## На что обратить внимание

- Старые файлы Tasker читает и без миграции (файл на диске при чтении не меняется); `migrate` нужна, чтобы все файлы лежали в текущем формате. Файл в формате новее, чем понимает ваша программа, не читается и не перезаписывается: `Unsupported format: …` — обновите `tasker`.
- Миграция ещё переименовывает файлы сущностей по названиям (у задач — по заголовкам); делайте её отдельным коммитом.
- `--check` ничего не пишет и завершается кодом 2, если есть что мигрировать или что-то требует внимания.
- Договоритесь в команде, кто мигрирует: иначе две ветки выполнят её независимо, и git покажет много конфликтов.
