Справка Tasker

Tasker — трекер задач рядом с кодом. Всё основное делается с клавиатуры: ниже все сочетания клавиш приложения.

Переходы

Палитра команд⌘ K
Задачи⌘ 1
Доски⌘ 2
Настройки⌘ 3
Админ-панель⌘ 4
Скрыть боковую панель⌘ 0

Задача

Сменить статус…⌥ ⌘ S
Связать с…⌘ L
Назначить родителя…⌥ ⌘ P
Скопировать ключ⌥ ⌘ C

Вид

По статусам⌥ ⌘ 1
Плоский⌥ ⌘ 2
Дерево⌥ ⌘ 3
Редактор доски⌥ ⌘ E

Список задач

Навигация по спискуJ K
Peek задачиSpace
Открыть задачу↵
Сменить статус выбранной задачиS
Закрыть peek или вернуться назадEsc

Файл и окна

Создать задачу⌘ N
Новая доска…⌥ ⌘ N
Новая вкладка⌘ T
Новое окно⇧ ⌘ N
Открыть папку…⌘ O
Закрыть вкладку⌘ W
Закрыть окно⇧ ⌘ W
Показать следующую вкладку⌃ ⇥
Показать предыдущую вкладку⌃ ⇧ ⇥
Настройки приложения⌘ ,

Справка

Справка Tasker⌘ ?
Сочетания клавиш⌥ ⌘ /

Сочетания с ⌘ работают из меню. Клавиши J, K, S, Пробел, Ввод и Esc работают в списке задач, пока курсор не в поле ввода.

Настройки приложения открываются по ⌘, : язык, тема и то, что открывать при запуске.
