# Блокировка на время правки

Занять запись, чтобы за время серии связанных правок её не изменил и не удалил кто-то другой (человек в десктопе, агент, другая команда).

## Что нужно

Запись, которую нужно править: проект, задача, тип задач, статус, доска, серия и т. п. Для одиночной команды блокировка не нужна: её защищает проверка версии.

## Шаги

```bash
tasker lock acquire task TSK-1
tasker task update TSK-1 --status "In progress"
tasker task update TSK-1 -d "Новое описание"
tasker lock release task TSK-1
```

Посмотреть, кто правит запись:

```bash
tasker lock show task TSK-1
```

## Пример

```text
$ tasker lock acquire task TSK-1
Locked Task eff86a1b-c516-4676-9aad-2feb7c3ff640 until 2026-10-02 14:33:22 +00:00

$ tasker lock show task TSK-1
Task eff86a1b-c516-4676-9aad-2feb7c3ff640 is edited by artem (console) (you) until 2026-10-02 14:33:22 +00:00
```

## На что обратить внимание

- Блокировка живёт 2 минуты и истекает сама; повторный `lock acquire` продлевает её.
- Чужую блокировку команды не обходят: `Locked: … is being edited by …`. Консоль и интерфейс десктопа считаются разными держателями.
- Имя в блокировках консоли показывает и меняет `tasker whoami`.
- Блокировка не передаётся между машинами через git: там остаётся проверка версии.
