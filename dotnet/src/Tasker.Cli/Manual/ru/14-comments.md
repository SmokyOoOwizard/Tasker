# Комментарии к задачам

Обсуждение прямо в задаче: дерево ответов от людей и агентов.

## Что нужно

Задача в проекте. Автор определяется сам: в консоли это локальный человек (`tasker whoami`), в MCP — агент.

## Шаги

```bash
tasker task comment add TSK-1 "Посмотрите, пожалуйста"
tasker task comment list TSK-1
tasker task comment add TSK-1 "Посмотрел" --reply-to 3f2a9c1e
tasker task comment edit TSK-1 3f2a9c1e "Посмотрел, всё верно"
tasker task comment delete TSK-1 3f2a9c1e
```

`list --json` отдаёт комментарии в порядке чтения: у каждого есть `parentId` и `depth`.

## Что важно

- Текст — Markdown, как в описании задачи.
- Отвечать можно на любой комментарий, вложенность не ограничена. На удалённый ответить нельзя.
- Менять и удалять можно только свой комментарий.
- У удалённого комментария с ответами ветка остаётся, на его месте пометка.
- При удалении задачи её комментарии удаляются. Если задачу удалили в другой ветке git, оставшиеся комментарии убирает `tasker cleanup`.
- Каждый комментарий — отдельный файл в `comments/`, поэтому ответы из разных веток git сливаются без конфликта.
