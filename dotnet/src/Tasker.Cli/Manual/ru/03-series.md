# Серии и ссылки TSK-N

Серия даёт задачам номера 1, 2, 3… и ссылку вида `TSK-5`: её удобно писать в коммитах и ветках, и ей можно указывать задачу в командах.

## Что нужно

Проект с типом задачи. Префикс серии: латинские буквы и цифры, до 20 символов.

## Шаги

```bash
tasker series create Tasks --prefix TSK
tasker task create "Первая задача" --type Task --series TSK
tasker task list --series TSK
tasker task get TSK-1
tasker series list
```

Задачу, созданную без серии, добавляют в неё потом; номер можно сменить:

```bash
tasker series add-task TSK 3c8e9eaa-c532-42ce-b308-c9445dd03a63
tasker series renumber-task TSK TSK-2 --to 10
```

## Пример

```text
Created series 'Tasks' (TSK) 3c8e9eaa-c532-42ce-b308-c9445dd03a63
Created task 'Первая задача' eff86a1b-c516-4676-9aad-2feb7c3ff640 (TSK-1)
```

## На что обратить внимание

- Регистр префикса важен: `TSK` и `tsk` — разные серии.
- Номер новой задачи — наибольший номер серии плюс один. Если удалить задачу с самым большим номером, этот номер выдадут заново.
- Задача может быть в нескольких сериях (`--series` повторяют), тогда у неё по номеру в каждой.
- После слияния веток git у двух задач может оказаться один номер. Это не ошибка, но их нужно развести: `tasker manual sync-cleanup`.
